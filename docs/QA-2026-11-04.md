## Findings

1. **F0 stalled once** at session state 3 (synchronized, not visible): timing, theater, screen and wrist checks failed
   together. Two reruns passed 23 / 23. Same pattern as the earlier F6 stalls: SteamVR withholding visibility.
2. **Fixed: library filters ran under the store menu** at narrow windows ("UNSUPPORTED 39" beneath "ALL STORES").
   The store and sort menus now take their own row when they don't fit.
3. **Fixed: the VR Game tab had no Reset** although it now holds settings. Reset puts back the game camera,
   Crosshair and Weapon in hand (to the all-games values); hidden objects stay, as they are undone one by one.
4. **Fixed (carried from 2026-10-30): the Already VR note said "This game" and "from Steam"** for apps and other
   stores. Now: "Already runs in VR on its own: start it in VR from Steam or its launcher."
5. **Fixed (carried from 2026-10-30): `Parallax.exe uninstall` on a game without VR** said "The system cannot find the
   file specified". Now: "VR isn't added to this game, so there is nothing to remove."
6. **Minor, not changed: library tab counts ignore the search.** With "zzzz" the tabs still read All 141. A taste
   call; counts that follow the search would explain an empty result faster.
